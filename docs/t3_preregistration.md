# Table 3 诊断：预先登记 (pre-registration)

作者 Zhang Qi · 写于 2026-11-11，**运行 `diagnose_gap.py` 与 `t3_diagnostics.py` 之前**。
主设定 (main specification) 不因下列任何结果而改变；所有结果无论方向如何都写进最终报告。

## 1. 要回答的问题

Table 2 复现成功：CAR 预测 CAPEX_ADJ（association，相关关系）。
Table 3 没有复现：论文说效应**只**出现在价差上升 (Higher spreads) 组，我们在两组都看到效应，组间差异 0.206，p = 0.672。
“复现失败”本身不是结论。需要判断是下面哪一种：

| 编号 | 解释 (explanation) | 含义 |
|---|---|---|
| E1 | 代理变量噪音 (proxy noise)：用 CRSP 日收盘报价、按“升/不升”二分，会把很多预测分错组 (misclassification)，两组系数被拉近 | 机制可能成立，只是论文的二分检验很脆弱 |
| E2 | 样本构成 / 数据版本 (sample composition, data vintage)：I/B/E/S 事后回填、早年覆盖不同、与财报同日的预测更多 | 论文的模式依赖于特定样本 |
| E3 | 论文 Table 3 的模式在当前数据中不稳健 (not robust)：真实的组间差异很小 | 相关关系成立，“知情交易反馈”这一机制解释得不到支持 |

三者不互斥。

## 3. 判定规则 (decision rule)

一共 7 个检验，纯靠运气在 10% 水平上出现 1 个显著也不奇怪，所以**单个检验显著不算数**：

* **支持 E1**：B 与 C **都**显示价差上升越多、效应越强（同方向，且至少一个 p < 0.05）。
* **支持 E2**：D1 与 E **都**出现论文模式（价差上升组显著、组间差异 p < 0.10）。
* **支持 E3**：A 的 CI 不含 1.501，且 B、C、D1、E 都没有出现上面的模式。
* 都不满足：如实报告“证据不足以区分”，并列出需要的额外数据（日内 TAQ 价差、作者样本）。
