# 预测层面定义的反推：预先登记

作者 Zhang Qi，写于 2026-11-12，在运行 `annual_waterfall.py` 和 `diagnose_definitions.py` 之前。

## 问题

公司层面的过滤（普通股、交易所、上市年限、链接评分）改变了样本中的公司，但 EA_DUM、预测类型比例、CAR 均值和 CAPEX_ADJ 均值几乎不变。这四个统计量取决于每个预测如何编码，因此差异应来自预测层面的定义。本轮检验论文没有写明的三处定义：

| 定义 | 备选 |
|---|---|
| 预测类型 (D3) | R0 当前规则；R1 把“上端 / 下端”（06、08）归为开放式；R2 只按 I/B/E/S 代码归类 |
| EA_DUM (D10) | E0 Compustat 财报日同一天；E1 ±1 天；E2 I/B/E/S 实际 EPS 公告日同一天；E3 ±1 天 |
| “盈利预测” (D9) | V1 仅 EPS；V2 盈利类指标（当前）；V3 同日任何其他指引；V4 V2 放宽到 ±1 天 |

## 规则

1. 只比较样本特征，与 `diagnose_gap.py` 使用同一距离 D。
2. 在所有组合中选 D 最小的一个，选定之前不跑回归。
3. 在选定组合上估计 Table 3（CAR 分组）一次。无论结果如何都报告，主设定不因此改变。
4. 判断标准：
   * 若选定组合的 D 明显小于当前设定，且 Table 3 出现论文模式（价差上升组显著、组间差异 p < 0.10），则说明 Table 3 的差异可由定义差异解释。
   * 若 D 明显下降，但 Table 3 仍不出现论文模式，则说明定义差异能解释描述统计，但不能解释 Table 3。
   * 若 D 下降不明显，则说明这三处定义都不是差异来源。

`annual_waterfall.py` 只计数，不跑回归。论文只报告逐年最终数和各步骤的全样本合计，因此无法计算论文的逐年保留率。本表比较两件事：一是“论文最终数 / 本复现第 k 步数量”在各年份是否平稳；二是 2003–2009 年在各步骤中所占的比重。
