      7估计方法

      7.1 回归方程

      CAPEX_ADJi,a,t = α + β · CAR_zi + γ′Xi + μfirm + τa + εi,a,t

      β 读作：市场反应高一个标准差（8.974 个百分点）时，实际 capex 相对预测多上调多少个百分点。各列的 X、固定效应和聚类见 §9。

      7.2 系数、标准误与 p 值

      1. 吸收固定效应：交替投影，把 y 和每个 x 依次对公司、年季去均值，重复直到变化小于 1e−10。
      2. 系数：β̂ = (X̃′X̃)−1X̃′ỹ，X̃、ỹ 为去均值后的数据；无固定效应时加常数项。
      3. 聚类稳健方差：V̂ = c · (X̃′X̃)−1 [Σg Sg′Sg] (X̃′X̃)−1，Sg = Σi∈g x̃iûi，c = G/(G−1) · (N−1)/(N−K)。
      4. 自由度 K：回归变量数加上未嵌套在聚类变量中的固定效应自由度（reghdfe 口径，D26）。公司固定效应嵌套在公司或行业聚类之内，因此不计入 K。
      5. p 值：t = β̂ / SE，p = 2 · Pr(tG−1 > |t|)。这解释了论文中 CAR_POS 的 t = 1.96 只标一颗星。
      6. Adj. R² = 1 − (1 − R²)(N − 1)/(N − k)，k 包含全部固定效应自由度；singletons 保留（D25：Table 2 有无公司固定效应时 N 相同）。
