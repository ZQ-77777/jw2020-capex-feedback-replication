# Replication package — Jayaraman & Wu (2020, RFS)

**"Should I Stay or Should I Grow? Using Voluntary Disclosure to Elicit Market Feedback"**,
*Review of Financial Studies* 33(8): 3854–3888, doi:10.1093/rfs/hhz132.

With `JW_SCOPE=all` every table and figure of the paper is covered: Table 1 (A–C), Table 2 (8 models), Table 3,
Table 4 (9 models), Table 5 Panels A–D, E1, E2, Table 6, Figure 1, plus the robustness numbers and
moments quoted in the text. Each output table prints **our estimate next to the paper's number**.

> ⚠️ The target numbers in `paper_targets.py` come from the **May-2019 working paper** (the only
> full text openly available). Download the published version through the HKUST library and
> check every target before reporting; see `REPLICATION_NOTES.md` §6.

## 1. Quick start

```bash
pip install -r requirements.txt

# (a) verify the code end-to-end WITHOUT WRDS (synthetic data, planted effect)  ~1 min
python tests/test_hdfe.py          # estimator == brute-force dummy OLS (areg) to 1e-8
python tests/run_synthetic.py      # generates data, runs every step, asserts the effect is recovered

# (0) is this machine ready? (env, packages, both test suites, data status -> verdict + next command)
python preflight.py

# (b) real run on WRDS  (step-by-step guide in Chinese: WRDS_GUIDE.md)
export WRDS_USERNAME=<account>     # needs IBES Guidance + CRSP + Compustat + TR + CRSP MF access
python check_wrds.py               # permissions, column names, CPX coding -> output/wrds_check.md
python pull_wrds.py                # -> data/raw/ + _pull_log.csv (dsf and s12 are pulled in chunks)
python diagnose.py                 # calibrate the IBES coding switches in config.py (REPLICATION_NOTES §4)
python run_all.py                  # -> data/interim/, output/ incl. replication_report.html
JW_SCOPE=all python run_all.py     # optional: every table (needs the 16-table pull)

# (c) optional cross-check of Tables 2-3 with Stata reghdfe on the identical rows
cd stata && stata -b do tables_2_3.do && cd ..   # or run the do-file from the Stata GUI
python compare_stata.py            # -> output/stata_crosscheck.md
```

## 2. Pipeline and file map

| Step | Script | Produces | Feeds |
|---|---|---|---|
| 00 | `check_wrds.py` | `output/wrds_check.md` | go / no-go before downloading |
| 01 | `pull_wrds.py` | `data/raw/*` (16 tables) | everything |
| — | `diagnose.py` | console report | switches D1, D3, D4, D9, D10 in `config.py` |
| 02a | `build_mf_pressure.py` | `mf_pressure` (MFFLOW, OUTFLOW, MF_OF by permno-quarter) | T5-E1, T5-E2, T6 |
| 02b | `build_capex_sample.py` | `capex_sample` (firm-quarter), `industry_erc`, `output/sample_waterfall.csv` | T1–T5 |
| 03 | `build_spread_panel.py` | `spread_panel` (event × day, capex + EPS forecasts) | T5-E1, Fig. 1 |
| 04 | `build_panel.py` | `forecast_panel` (all firm-quarters) | T6 |
| 05 | `tables.py` | `output/tables.md`, `output/estimates_long.csv`, `output/figure1_spreads.png` | — |

Pre-data report for the supervisor (Chinese): `docs/REPORT_PREDATA_zh.html`, regenerated by
`python docs/build_report_zh.py` (code excerpts and line numbers are cut from the source files).

Guides: `GUIDE.html` (open in a browser: overview, searchable variable dictionary and decision log,
checklist), `WRDS_GUIDE.md` (WRDS account, Duo, download, calibration, troubleshooting),
`REPLICATION_NOTES.md` (decision log D1–D37). `.gitignore` keeps licensed WRDS data out of Git.

Supporting modules: `config.py` (all switches), `utils.py` (links, event windows, winsorising),
`hdfe.py` (fixed-effects OLS with clustered SEs, Stata conventions), `paper_targets.py`.

Put these two hand-collected files in `data/external/` (the code skips the panel if absent):

* `pin.csv` — columns `permno, year, qtr, pin`: Brown–Hillegeist–Lo quarterly PIN estimates
  (posted by Stephen Brown; ends in 2010, which is why Table 5A stops in 2010).
* `pay_duration.csv` — columns `gvkey, year, duration`: Gopalan, Milbourn, Song & Thakor (2014)
  pay duration (the authors received it from Todd Milbourn; ask the authors, 2006–2009 only).

## 4. Reading the output

* `output/sample_waterfall.csv` — our counts at each filter vs. the paper (40,785 → 36,900 → 19,427 → 17,577).
* `output/tables.md` — every table, `ours` row then `paper` row; N and adjusted R² underneath.
* `output/estimates_long.csv` — one row per coefficient (table, model, var, coef, se, p, N, paper_coef, paper_se):
  the file to compute "how close are we" summaries from.

Exact equality is not expected (IBES Guidance and Compustat have been revised since 2019, and the
paper leaves 37 choices unstated, D1–D37). The bar is: same sample size within ~5–10%, same signs, same
significance pattern, similar magnitudes. Every choice is a switch in `config.py`, logged in
`REPLICATION_NOTES.md`, so differences can be traced and tested.
